# Auditoria de segurança: graphifyy 0.9.91 (sdist PyPI)

Data: 2026-10-15. Escopo: leitura estática (Read/Grep), sem instalar nem executar código do pacote, sem ler .env ou segredos.
Pacote: `C:\DRSAUDEMENTAL\scratchpad\ext\graphify\graphifyy-0.9.91` (caminhos abaixo relativos a `graphify/`, salvo indicação).

## Veredito: APROVADO COM RESTRIÇÕES

Não há código malicioso, telemetria, exfiltração oculta, eval/exec/pickle, nem alteração de ANTHROPIC_BASE_URL. O núcleo (extração por tree-sitter) é 100% local. Os riscos são de CONFIGURAÇÃO e de CUSTO/PRIVACIDADE, não de malware: (1) o skill manda o Claude disparar subagentes em paralelo para docs/PDF/imagens (consome a cota do Claude Code e contraria a regra 3 do CLAUDE.md), (2) com `GEMINI_API_KEY`/`GOOGLE_API_KEY` no ambiente o corpus de documentos vai ao Google, (3) o instalador reescreve CLAUDE.md e `.claude/settings.json`.

### Restrições obrigatórias para o Portal
1. Usar SOMENTE o modo local: `graphify extract . --code-only` e `graphify update .` (AST, sem LLM). Nunca rodar `/graphify` completo, `graphify extract` sem `--code-only`, `graphify cluster-only`/`label` sem `--no-label`, nem `--dedup-llm`.
2. Antes de usar: garantir que NENHUMA chave de LLM esteja no ambiente do shell (GEMINI/GOOGLE/MOONSHOT/ANTHROPIC/OPENAI/DEEPSEEK/AZURE/AWS_*/OLLAMA_*). `detect_backend()` escolhe o provedor automaticamente pela primeira chave encontrada (llm.py:3375-3396).
3. NÃO rodar `graphify install` (global) nem `graphify claude install`/`install --project`: escrevem em `~/.claude/skills`, `~/.claude/CLAUDE.md`, `./CLAUDE.md` (que tem regras do CFM/LGPD) e `.claude/settings.json`. Se quiser o hook, adicionar manualmente só o bloco do item 5, depois de revisar.
4. Criar `.graphifyignore` (e manter `.gitignore`) excluindo, no mínimo: `backend/data/`, `importacao-completa/`, `importacao-extra-180/`, `referencias-140-prontas/`, `carrosseis-instagram/`, `backups/`, `relatorios/`, `node_modules/`, `.next/`, `graphify-out/`, `client_secret.json`, `upload_r2.py`, `scratchpad/`, `*.mp3`, `*.mp4`. Adicionar `graphify-out/` ao `.gitignore`.
5. Definir `GRAPHIFY_NO_TIPS=1`, `GRAPHIFY_NO_AUTO_REFRESH=1`; não habilitar `GRAPHIFY_QUERY_LOG*`.
6. Instalar em venv isolado (ou `uv tool`), sem extras (`pip install graphifyy` puro, sem `[all]`); conferir o nome do pacote (duplo "y") contra o repositório oficial github.com/Graphify-Labs/graphify antes de instalar; fixar versão 0.9.91 e rodar `pip-audit` nas dependências.
7. Não instalar hook git (`graphify hook install`) sem revisão: grava `.git/hooks/post-commit|post-checkout|post-merge` e log em `~/.cache/graphify-rebuild.log`.
